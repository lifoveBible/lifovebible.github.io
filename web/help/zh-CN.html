Lifove Bible 网页版

这是把 Android App「Lifove Bible」带到浏览器上的圣经阅读器。使用与 App 相同的圣经资料，完全免费，没有广告。可在 iPhone、iPad、电脑、Mac，以及 Android 手机或平板的浏览器中开启。

  • 换章：将经文向左或向右滑动，或按 ‹ › 按钮。在电脑上也可以用 ← → 键。
  • 选取经节：点一下经节即可选取，再点一下取消。选取的经节可以复制或分享。
  • 精选：选取经节后，按下方列中的 精选 即可上色，按 取消 即可清除。每个译本的精选分开保存。在 ☰ →我的精选 中可以看到全部，点一下即可前往该经节。
  • 备忘：选取一节经文后，按下方列中的 备忘，画面下方会开启备忘栏。写好后按 储存，备忘会以小字显示在经节下方。之后可以再次修改或 删除（储存空白内容也会删除）。☰ →隐藏备忘 后只会显示 ★，点 ★ 即可开启备忘。
  • 书签：☰ →加入书签 会储存画面最上方的经节。在 ☰ →书签 中点选已储存的位置，即可前往该经节。
  • 下载：已下载的译本不需连上网路也能阅读。
  • 单一检视・并列检视：切换译本，或并排阅读多个译本。
  • 搜寻：用两个关键字和范围（全部、旧约、新约、分类、书卷）搜寻。
  • 加入圣经档案：加入你拥有的圣经档案（.lfa、.bdf）。
  • 资料备份：☰ →资料备份与恢复 →进行备份，会把精选、备忘、阅读纪录和书签下载成一个档案（.db）。这是与 Android App 相同的备份档，也可以在 App 的「设定 → 恢复资料」中开启。
  • 恢复资料：☰ →资料备份与恢复 →进行恢复，然后选择备份档。也可以使用 Android App 的备份（Download/LifoveBible 中的 .db 档，或旧版本的 lifovebible）。合并 会保留目前的纪录并加入备份中的纪录（内容不同的备忘由你选择）；取代 会删除目前的纪录，改用备份。
  • 阅读器设定：列的位置、文字与背景颜色、移动按钮。
  • 朗读：按书卷・章栏的▶，即以装置的语音（TTS）朗读本章，读完后自动前往下一章。朗读时按▶位置上的1.0x可改变速度，并可在栏上新出现的一列暂停、停止或换章。对照检视时朗读第一个译本。

语音使用装置内建的声音，因此各装置不同；没有该语言的语音时无法朗读。朗读时会让萤幕保持开启，但切换到其他应用程式或关闭萤幕时可能会停止。

安装朗读用的声音

朗读使用装置上已安装的声音。网页应用程式无法开启装置的设定画面，请点下方您使用的装置并照着做。安装后，可能要把浏览器（或已安装的应用程式）完全关闭再重新开启，新的声音才会出现在清单中。声音可在阅读器设定 → 语音（TTS）设定 → 声音中选择。

Android
  1. 在 Play 商店安装或更新Google 语音辨识和语音合成。
  2. 在设定应用程式中搜寻文字转语音并开启。
  3. 将偏好的引擎设为 Google，点旁边的 ⚙ → 安装语音资料，下载需要的语言。

Chrome 只会显示偏好引擎的声音。三星引擎的声音在网页上可能无法使用。

iPhone · iPad
  1. 前往设定 → 辅助使用 → 朗读与说话（语音内容）→ 声音。
  2. 选择语言，点声音旁的下载按钮。「增强」的声音较自然。
PC · Mac
  • Windows：设定 → 时间与语言 → 语音 → 新增语音。Edge 连上网路时也会显示自然的线上声音。
  • Mac：系统设定 → 辅助使用 → 语音内容 → 点系统声音旁的 ⓘ 下载声音。
  • Chrome 连上网路时也会显示 Google 的声音（需要网路）。

安装方法

你现在正在使用已安装的 App。

安装到主画面或桌面后，就能像 App 一样从图示开启，没有网址列，离线也能使用。不需要 App Store，而且档案非常小。请点选下方你的装置。

iPhone・iPad

需要 iOS（iPadOS）16.4 以上。

Safari

  1. 用 Safari 开启这个页面。
  2. 点选分享按钮（□↑）：iPhone 在画面下方，iPad 在网址列右上方。如果找不到，请点网址列旁的 ⋯，再点 分享。
  3. 往下卷动，点选 加入主画面。（若有 以网页 App 打开，请保持开启）
  4. 点右上角的 新增。

Chrome・Edge・Firefox

  1. 点网址列右侧的分享按钮（□↑）。在 Edge 或 Firefox 中，它可能在选单（⋯ 或 ≡）里。
  2. 点选 加入主画面 →新增。

请注意。 在 iPhone 上，浏览器分页和主画面 App 的储存空间是分开的。在浏览器中下载的译本和设定不会出现在主画面 App 中，因此安装后请从主画面图示开启，并在 下载 中重新下载译本。另外，如果不安装、只在浏览器中使用，iPhone 可能会在一段时间没有开启后删除已下载的译本，因此建议安装。

Android 手机・平板

在 Android 上，Google Play 的 Lifove Bible App 功能更多（笔记、阅读标记、朗读等）。安装网页版的方法：

Chrome

  1. 如果画面下方出现 安装 提示，请点选它。
  2. 如果没有，请点右上角的选单（⋮）→安装应用程式 或 加到主画面 →安装。

Samsung Internet

  1. 如果网址列出现安装图示（↓），请点选它。
  2. 如果没有，请点下方的选单（≡）→新增页面至 →主画面。

Edge・Firefox・其他

在选单（⋯ 或 ⋮）中，点选 安装应用程式、安装 或 加到主画面 等项目。

电脑・Mac・Chromebook

Chrome（Windows、Mac、Linux、Chromebook）

  1. 点网址列右端的安装图示（带箭头的萤幕），然后点 安装。
  2. 如果没有图示，请开启选单（⋮）→投放、储存及分享 →将网页安装为应用程式。

Edge（Windows、Mac）

  1. 点网址列中的应用程式图示（有可用的应用程式），然后点 安装。
  2. 如果没有图示，请开启选单（⋯）→应用程式 →将此网站安装为应用程式。

Safari（Mac）

在 macOS 14（Sonoma）以上，从选单列选择 档案 →加入 Dock。

Firefox

Firefox 无法将网站安装为 App。请加入书签，或使用 Chrome 或 Edge 安装。

Windows 平板与电脑相同。

移除已安装的 App

  • iPhone・iPad：长按图示 →移除 App →删除（或 从主画面移除）。
  • Android：长按图示 →解除安装（或 应用程式资讯 →解除安装）。
  • 电脑：在 App 视窗右上角开启选单（⋮ 或 ⋯）→解除安装。在 Chrome 中也可以前往 chrome://apps。
  • Mac 的 Safari：把图示拖出 Dock，或从「应用程式」资料夹删除。

更新

不需要做任何事。新版本准备好时，画面上方会出现「有新版本」。点 重新载入 即可更新。

我的译本和设定存在哪里？

它们储存在这部装置的这个浏览器中，不会与其他装置或浏览器共用。在浏览器设定中清除网站资料（Cookie 和网站资料）时，这些也会一并删除；只要重新下载译本即可。

请务必备份你的纪录（精选、备忘）

精选、备忘、书签和阅读纪录也只储存在这个浏览器中，不会另外保存在伺服器上。若清除网站资料、储存空间不足，或更换装置或浏览器，纪录可能会遗失，而遗失的纪录无法复原。iPhone、iPad 的 Safari 若未加入主画面，且超过 7 天没有开启，也可能会删除纪录。

请在 ☰ →资料备份与恢复 中定期备份，并将档案保存在电脑或云端硬碟等安全的地方。距离上次备份超过 7 天时，会在画面上方提醒您（按 稍后 会在 7 天后再次提醒）。

备份档也可以在其他装置上使用。透过电子邮件、通讯软体、云端硬碟等方式移动档案后，在 Android 手机或平板的 Lifove Bible App 中到「设定 → 恢复资料」，或在其他装置或浏览器的网页版中按 ☰ →资料备份与恢复 →进行恢复，选择该档案，即可继续使用精选、备忘等纪录。更换装置时也请这样移动。

备份及备份档的保存需要由您自行管理。因未备份而遗失的纪录，我们无法为您复原，此责任由使用者自行承担，敬请见谅。
