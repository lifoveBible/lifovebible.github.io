Lifove Bible 웹 버전

안드로이드 앱 Lifove Bible을 브라우저에서 쓸 수 있게 만든 성경 뷰어입니다. 앱과 같은 성경 데이터를 쓰고, 광고 없이 무료입니다. 아이폰, 아이패드, PC, 맥, 안드로이드 폰·태블릿 어디서나 브라우저로 열면 됩니다.

  • 장 넘기기: 본문을 왼쪽이나 오른쪽으로 밀거나, 이동 버튼 ‹ ›를 누릅니다. PC에서는 키보드 ← →도 됩니다.
  • 절 고르기: 절을 누르면 고르고, 다시 누르면 풉니다. 여러 절을 골라 복사하거나 공유할 수 있습니다.
  • 형광펜: 절을 고른 뒤 아래 띠의 형광펜을 누르면 칠하고, 지우기를 누르면 지웁니다. 역본마다 따로 칠해집니다. 칠한 절은 ☰ → 나의형광펜목록에서 모아 보고, 누르면 그 절로 갑니다.
  • 메모: 절 하나를 고른 뒤 아래 띠의 메모를 누르면 화면 아래에 입력판이 열립니다. 쓰고 저장을 누르면 절 아래에 작게 보입니다. 다시 고쳐 쓰거나 삭제할 수 있고, 비운 채 저장해도 지워집니다. ☰ → 메모 숨기기를 누르면 ★만 보이고, ★를 누르면 메모가 열립니다.
  • 책갈피: ☰ → 책갈피 추가를 누르면 화면 맨 위에 보이는 절을 저장합니다. ☰ → 책갈피에서 저장한 곳을 누르면 그 절로 갑니다.
  • 성경다운로드: 읽을 역본을 받아 두면 인터넷 없이도 읽을 수 있습니다.
  • 다른성경보기 · 역본대조보기: 역본을 바꾸거나 여러 역본을 나란히 봅니다.
  • 검색: 검색어 두 개와 범위(전체, 구약, 신약, 주제별, 책)로 찾습니다.
  • 성경 파일 넣기: 가지고 있는 성경 파일(.lfa, .bdf)을 넣어 봅니다.
  • 데이터 백업: ☰ → 데이터 백업·복구 → 백업 실행을 누르면 형광펜, 메모, 읽기통계, 책갈피를 파일 하나(.db)로 내려받습니다. 안드로이드 앱과 같은 백업 파일이라 앱의 설정 → 데이터 복구로도 열 수 있습니다.
  • 데이터 복구: ☰ → 데이터 백업·복구 → 복구 실행에서 백업 파일을 고릅니다. 안드로이드 앱의 백업(다운로드/LifoveBible 폴더의 .db, 옛 버전의 lifovebible)도 됩니다. 합치기는 지금 기록을 두고 백업의 기록을 더하고(내용이 다른 메모는 하나씩 고름), 바꾸기는 지금 기록을 지우고 백업으로 바꿉니다.
  • 본문화면설정: 책·장 바 위치, 글자색·배경색, 이동 버튼을 바꿉니다.
  • 음성 읽기: 책·장 바의 ▶를 누르면 기기의 음성(TTS)으로 지금 장을 읽고, 장이 끝나면 다음 장으로 넘어갑니다. 읽는 동안 ▶ 자리의 1.0x를 누르면 속도가 바뀌고, 바에 생긴 줄에서 멈추거나 장을 옮깁니다. 대조 보기에서는 첫 역본을 읽습니다.

음성은 기기에 깔린 것을 써서 기기마다 다르고, 그 언어의 음성이 없으면 읽지 못합니다. 읽는 동안에는 화면이 꺼지지 않게 해 두지만, 다른 앱으로 가거나 화면을 끄면 멈출 수 있습니다.

음성 읽기 목소리 설치

음성 읽기는 기기에 깔린 목소리를 씁니다. 웹 앱은 기기 설정 화면을 열 수 없으니 아래에서 쓰시는 기기를 눌러 따라 해 주세요. 설치한 뒤에는 브라우저(또는 설치한 앱)를 완전히 닫았다가 다시 열어야 목록에 나타날 수 있습니다. 목소리는 본문화면설정 → 음성(TTS) 설정 → 목소리에서 고릅니다.

안드로이드
  1. 플레이스토어에서 Google 음성 인식 및 합성을 설치하거나 업데이트합니다.
  2. 폰 설정 앱 위쪽 검색에 텍스트 음성 변환을 입력해 들어갑니다. 삼성 폰은 보통 설정 → 일반 → 텍스트 음성 변환입니다.
  3. 기본 엔진을 Google로 고르고, 옆의 ⚙ → 음성 데이터 설치에서 필요한 언어를 받습니다.

크롬은 기본 엔진의 목소리만 보여 줍니다. 삼성 엔진의 목소리는 웹에서 쓰지 못할 수 있습니다.

아이폰 · 아이패드
  1. 설정 → 손쉬운 사용 → 읽기 및 말하기 → 음성으로 갑니다. 옛 iOS는 손쉬운 사용 → 음성 콘텐츠 → 음성입니다.
  2. 언어를 고르고 목소리 옆의 받기 단추를 누릅니다. '향상된' 목소리가 더 자연스럽습니다.
PC · 맥
  • 윈도우: 설정 → 시간 및 언어 → 음성 → 음성 추가. 엣지는 인터넷이 될 때 자연스러운 온라인 목소리도 보여 줍니다.
  • 맥: 시스템 설정 → 손쉬운 사용 → 읽기 및 말하기 → 시스템 목소리 옆 ⓘ에서 목소리를 받습니다.
  • 크롬은 인터넷이 될 때 Google 목소리(인터넷 필요)도 보여 줍니다.

설치하는 법

지금 설치한 앱으로 보고 계십니다.

홈 화면이나 바탕화면에 설치하면 아이콘을 눌러 앱처럼 열고, 주소창 없이 넓게 보며, 인터넷 없이도 열립니다. 앱 스토어를 거치지 않고 크기도 아주 작습니다. 아래에서 쓰시는 기기를 눌러 보세요.

아이폰 · 아이패드

iOS(iPadOS) 16.4 이상이 필요합니다.

사파리

  1. 사파리에서 이 페이지를 엽니다.
  2. 공유 버튼(□↑)을 누릅니다. 아이폰은 화면 아래, 아이패드는 위쪽 주소창 오른쪽에 있습니다. 보이지 않으면 주소창 옆 ⋯을 누른 뒤 공유를 누릅니다.
  3. 목록을 올려 홈 화면에 추가를 누릅니다. (웹 앱으로 열기가 보이면 켜 둡니다.)
  4. 오른쪽 위 추가를 누릅니다.

크롬 · 엣지 · 파이어폭스

  1. 주소창 오른쪽의 공유 버튼(□↑)을 누릅니다. 엣지·파이어폭스는 메뉴(⋯ 또는 ≡) 안에 있을 수 있습니다.
  2. 홈 화면에 추가 → 추가를 누릅니다.

꼭 읽어 주세요. 아이폰에서는 브라우저 탭과 홈 화면 앱의 저장 공간이 따로입니다. 브라우저에서 받은 역본과 설정은 홈 화면 앱에 없으니, 설치한 뒤에는 홈 화면 아이콘으로 열고 성경다운로드에서 역본을 다시 받으세요. 또 아이폰은 설치하지 않고 브라우저로만 쓰면 한동안 열지 않았을 때 받은 역본을 지울 수 있으니 설치해서 쓰시기를 권합니다.

안드로이드 폰 · 태블릿

안드로이드에서는 Google Play의 Lifove Bible 앱이 기능이 더 많습니다(메모, 읽음 표시, 음성 낭독 등). 웹 버전을 설치하려면:

크롬

  1. 아래쪽에 설치 안내가 뜨면 누릅니다.
  2. 뜨지 않으면 오른쪽 위 메뉴(⋮) → 앱 설치 또는 홈 화면에 추가 → 설치를 누릅니다.

삼성 인터넷

  1. 주소창에 설치 아이콘(↓)이 보이면 누릅니다.
  2. 없으면 아래 메뉴(≡) → 현재 페이지 추가 → 홈 화면을 누릅니다.

엣지 · 파이어폭스 · 웨일 등

메뉴(⋯ 또는 ⋮)에서 앱 설치, 설치, 홈 화면에 추가 같은 항목을 누릅니다.

PC · 맥 · 크롬북

크롬 (윈도우, 맥, 리눅스, 크롬북)

  1. 주소창 오른쪽 끝의 설치 아이콘(모니터에 화살표 모양)을 누르고 설치를 누릅니다.
  2. 아이콘이 없으면 오른쪽 위 메뉴(⋮) → 전송, 저장, 공유 → 페이지를 앱으로 설치를 누릅니다.

엣지 (윈도우, 맥)

  1. 주소창 오른쪽의 앱 아이콘(앱 사용 가능)을 누르고 설치를 누릅니다.
  2. 아이콘이 없으면 메뉴(⋯) → 앱 → 이 사이트를 앱으로 설치를 누릅니다.

웨일

주소창 오른쪽의 설치 아이콘을 누릅니다. 크롬과 비슷합니다.

사파리 (맥)

macOS 14(소노마) 이상에서 메뉴 막대 파일 → Dock에 추가를 누릅니다.

파이어폭스

앱으로 설치하는 기능이 없습니다. 북마크해 두고 쓰시거나, 설치하려면 크롬·엣지를 쓰세요.

윈도우 태블릿은 PC와 같습니다.

설치한 앱 지우기

  • 아이폰 · 아이패드: 홈 화면 아이콘을 길게 누름 → 앱 제거 → 삭제(또는 홈 화면에서 제거).
  • 안드로이드: 아이콘을 길게 누름 → 제거(또는 앱 정보 → 제거).
  • PC: 앱 창 오른쪽 위 메뉴(⋮ 또는 ⋯) → 제거. 크롬은 주소창에 chrome://apps를 넣어 지울 수도 있습니다.
  • 맥 사파리: Dock에서 아이콘을 끌어내거나, 응용 프로그램 폴더에서 지웁니다.

업데이트

따로 할 일은 없습니다. 새 버전이 나오면 화면 위에 "새 버전이 있습니다"가 뜨고, 새로 고침을 누르면 바뀝니다.

받은 역본과 설정은 어디에 있나요?

이 기기의 이 브라우저 안에 저장됩니다. 다른 기기나 다른 브라우저와는 나눠지지 않습니다. 브라우저 설정에서 사이트 데이터(쿠키 및 사이트 데이터)를 지우면 함께 지워지니, 그때는 성경다운로드에서 다시 받으세요.

내 기록(형광펜·메모)은 꼭 백업해 주세요

형광펜, 메모, 책갈피, 읽기 기록도 이 브라우저 안에만 저장되며, 서버에는 따로 보관되지 않습니다. 사이트 데이터를 지우거나, 저장 공간이 부족하거나, 기기나 브라우저를 바꾸면 사라질 수 있고, 사라진 기록은 되살릴 방법이 없습니다. 아이폰·아이패드의 사파리는 홈 화면에 추가하지 않은 채 7일 넘게 열지 않으면 기록을 지울 수도 있습니다.

☰ → 데이터 백업·복구에서 정기적으로 백업해 주시고, 받은 파일은 PC나 클라우드 드라이브처럼 안전한 곳에 함께 보관해 주세요. 백업한 지 7일이 지나면 화면 위에 알려 드립니다(나중에를 누르면 7일 뒤에 다시 알려 드립니다).

백업 파일은 다른 기기에서도 쓸 수 있습니다. 메일, 메신저, 클라우드 드라이브 등으로 파일을 옮긴 뒤 안드로이드 폰·태블릿의 Lifove Bible 앱에서는 설정 → 데이터 복구, 다른 기기나 브라우저의 웹 버전에서는 ☰ → 데이터 백업·복구 → 복구 실행으로 그 파일을 고르면 형광펜, 메모 등을 이어서 쓸 수 있습니다. 기기를 바꿀 때도 이렇게 옮기세요.

백업과 백업 파일 보관은 사용자께서 직접 관리해 주셔야 합니다. 백업하지 않아 사라진 기록은 저희가 되돌려 드릴 수 없으며, 그 책임은 사용자께 있다는 점을 너그러이 양해해 주시기 바랍니다.

문의와 건의

필요한 기능이나 버그는 개발 사이트에 남기시거나 bible@lifove.net으로 메일을 보내 주세요.
