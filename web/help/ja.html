Lifove Bible ウェブ版

AndroidアプリLifove Bibleをブラウザで使えるようにした聖書ビューアです。アプリと同じ聖書データを使い、無料で広告もありません。iPhone、iPad、パソコン、Mac、Androidのスマートフォンやタブレットのブラウザで開けます。

  • 章の移動: 本文を左右にスワイプするか、‹ › ボタンを押します。パソコンでは ← → キーも使えます。
  • 節を選ぶ: 節をタップすると選ばれ、もう一度タップすると選択が外れます。選んだ節はコピーや共有ができます。
  • 線を引く: 節を選んでから、下のバーの 線を引く を押すと色が付き、消す で消えます。線は訳ごとに別々に保存されます。☰ → マイライン で一覧を見られ、タップするとその節に移動します。
  • メモ: 節を一つ選んでから、下のバーの メモ を押すと、画面の下にメモ欄が開きます。書いて 保存 を押すと、節の下に小さな文字でメモが表示されます。もう一度開いて直したり、削除 したりできます(空のまま保存しても削除されます)。☰ → メモを隠す にすると ★ だけが表示され、★ をタップするとメモが開きます。
  • しおり: ☰ → しおりを追加 で、画面のいちばん上の節を保存します。☰ → しおり で保存した所をタップすると、その節に移動します。
  • ダウンロード: ダウンロードした訳は、インターネットにつながっていなくても読めます。
  • 聖書を選ぶ・訳を比較: 訳を切り替えたり、複数の訳を並べて読んだりできます。
  • 検索: 二つのキーワードと範囲(全体、旧約、新約、テーマ別、書)で検索します。
  • 聖書ファイルの追加: お持ちの聖書ファイル(.lfa, .bdf)を追加します。
  • データのバックアップ: ☰ → バックアップと復元 → バックアップする で、線、メモ、既読の記録、しおりを一つのファイル(.db)としてダウンロードします。Androidアプリと同じバックアップファイルなので、アプリの[設定] → [データの復元]でも開けます。
  • データの復元: ☰ → バックアップと復元 → 復元する を押して、バックアップファイルを選びます。Androidアプリのバックアップ(Download/LifoveBibleの .db ファイル、または旧バージョンの lifovebible)も使えます。統合 は今の記録を残したままバックアップの記録を加え(内容が違うメモは選びます)、置き換え は今の記録を消してバックアップに置き換えます。
  • 本文の設定: バーの位置、文字と背景の色、移動ボタン。
  • 読み上げ: 書・章バーの▶を押すと、端末の音声(TTS)で今の章を読み上げ、章が終わると次の章へ進みます。読み上げ中は▶の位置の1.0xを押すと速度が変わり、バーに出る列で一時停止・停止・章の移動ができます。対照表示では最初の訳を読みます。節を選んでから▶を押すと、その節から読み上げます。

音声は端末に入っているものを使うため端末ごとに異なり、その言語の音声がなければ読み上げられません。読み上げ中は画面が消えないようにしますが、別のアプリに切り替えたり画面を消したりすると止まることがあります。

読み上げの音声をインストールする

読み上げには端末に入っている音声を使います。ウェブアプリは端末の設定画面を開けないため、下でお使いの端末を押して手順に従ってください。インストール後は、ブラウザ(またはインストールしたアプリ)を完全に閉じて開き直すと一覧に出てきます。声は本文の設定 → 読み上げ(TTS)の設定 → 声で選びます。

Android
  1. Play ストアでGoogle 音声認識と音声合成をインストールまたは更新します。
  2. 設定アプリの検索でテキスト読み上げを探して開きます。
  3. 優先するエンジンを Google にし、横の ⚙ → 音声データのインストールで必要な言語をダウンロードします。

Chrome は優先するエンジンの声だけを表示します。Samsung のエンジンの声はウェブでは使えないことがあります。

iPhone · iPad
  1. 設定 → アクセシビリティ → 読み上げ(読み上げコンテンツ) → 声を開きます。
  2. 言語を選び、声の横のダウンロードボタンを押します。「拡張」の声のほうが自然です。
PC · Mac
  • Windows: 設定 → 時刻と言語 → 音声認識 → 音声の追加。Edge はインターネットにつながっていると自然なオンラインの声も表示します。
  • Mac: システム設定 → アクセシビリティ → 読み上げコンテンツ → システムの声の横の ⓘ で声をダウンロードします。
  • Chrome はインターネットにつながっていると Google の声(インターネットが必要)も表示します。

インストールのしかた

今、インストールしたアプリで使っています。

ホーム画面やデスクトップにインストールすると、アイコンからアプリのように開け、アドレスバーなしで、オフラインでも使えます。アプリストアは必要なく、とても小さいです。下からお使いの端末を選んでください。

iPhone · iPad

iOS(iPadOS)16.4以降が必要です。

Safari

  1. このページをSafariで開きます。
  2. 共有ボタン(□↑)を押します。iPhoneでは画面の下、iPadではアドレスバーの右上にあります。見つからないときは、アドレスバーの横の ⋯ を押してから 共有 を押します。
  3. 下にスクロールして ホーム画面に追加 を押します。(Webアプリとして開く があれば、オンのままにします)
  4. 右上の 追加 を押します。

Chrome · Edge · Firefox

  1. アドレスバーの右の共有ボタン(□↑)を押します。EdgeやFirefoxでは、メニュー(⋯ または ≡)の中にあることがあります。
  2. ホーム画面に追加 → 追加 を押します。

ご注意ください。 iPhoneでは、ブラウザのタブとホーム画面のアプリは保存場所が別々です。ブラウザでダウンロードした訳や設定はホーム画面のアプリにはないので、インストールしたらホーム画面のアイコンから開いて、ダウンロード で訳をもう一度ダウンロードしてください。また、インストールせずブラウザだけで使っていると、しばらく開かないうちにiPhoneがダウンロードした訳を削除することがあるため、インストールをおすすめします。

Androidスマートフォン · タブレット

Androidでは、Google PlayのLifove Bibleアプリのほうが機能が多くあります(ノート、既読の記録、読み上げなど)。ウェブ版をインストールするには:

Chrome

  1. 画面の下に インストール の案内が出たら、それを押します。
  2. 出ないときは、右上のメニュー(⋮)→ アプリをインストール または ホーム画面に追加 → インストール を押します。

Samsung Internet

  1. アドレスバーにインストールのアイコン(↓)が出たら、それを押します。
  2. 出ないときは、下のメニュー(≡)→ ページを追加 → ホーム画面 を押します。

Edge · Firefox · そのほか

メニュー(⋯ または ⋮)で、アプリをインストール、インストール、ホーム画面に追加 などの項目を押します。

パソコン · Mac · Chromebook

Chrome(Windows、Mac、Linux、Chromebook)

  1. アドレスバーの右端にあるインストールのアイコン(矢印の付いたモニター)をクリックし、インストール を押します。
  2. アイコンがないときは、メニュー(⋮)→ キャスト、保存、共有 → ページをアプリとしてインストール を選びます。

Edge(Windows、Mac)

  1. アドレスバーのアプリのアイコン(アプリを利用できます)をクリックし、インストール を押します。
  2. アイコンがないときは、メニュー(⋯)→ アプリ → このサイトをアプリとしてインストール を選びます。

Safari(Mac)

macOS 14(Sonoma)以降では、メニューバーの ファイル → Dockに追加 を選びます。

Firefox

Firefoxではサイトをアプリとしてインストールできません。ブックマークするか、ChromeやEdgeでインストールしてください。

Windowsタブレットもパソコンと同じです。

インストールしたアプリを削除する

  • iPhone · iPad: アイコンを長押し → アプリを削除 → 削除(または ホーム画面から取り除く)。
  • Android: アイコンを長押し → アンインストール(または アプリ情報 → アンインストール)。
  • パソコン: アプリのウィンドウの右上のメニュー(⋮ または ⋯)→ アンインストール。Chromeでは chrome://apps からもできます。
  • MacのSafari: アイコンをDockの外へドラッグするか、アプリケーションフォルダから削除します。

アップデート

何もする必要はありません。新しいバージョンの準備ができると、「新しいバージョンがあります」と画面の上に表示されます。再読み込み を押すと切り替わります。

訳や設定はどこにありますか?

この端末のこのブラウザの中に保存され、ほかの端末やブラウザとは共有されません。ブラウザの設定でサイトデータ(Cookieとサイトデータ)を消すと、これらも消えます。訳はもう一度ダウンロードしてください。

記録(線、メモ)を必ずバックアップしてください

線、メモ、しおり、既読の記録も、このブラウザの中にだけ保存され、サーバーには保管されません。サイトデータを消したり、保存容量が足りなくなったり、端末やブラウザを替えたりすると記録が失われることがあり、失われた記録を元に戻す方法はありません。iPhone・iPadのSafariでは、ホーム画面に追加しないまま7日以上開かないと、記録が削除されることもあります。

☰ → バックアップと復元 で定期的にバックアップし、ファイルはパソコンやクラウドドライブなど安全な場所に保管してください。最後のバックアップから7日が過ぎると、画面の上でお知らせします(あとで を押すと7日後にもう一度お知らせします)。

バックアップファイルはほかの端末でも使えます。メール、メッセンジャー、クラウドドライブなどでファイルを移し、AndroidスマートフォンやタブレットのLifove Bibleアプリでは[設定] → [データの復元]、ほかの端末やブラウザのウェブ版では ☰ → バックアップと復元 → 復元する でそのファイルを選ぶと、線やメモなどを引き続き使えます。端末を替えるときも、このように移してください。

バックアップとバックアップファイルの保管は、ご自身で管理していただく必要があります。バックアップしなかったために失われた記録を私たちが元に戻すことはできず、その責任はご利用者様にあることを、どうかご了承ください。
