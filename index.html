하나의 성경, 두 가지 앱

쓰는 기기에 맞는 앱을 고르세요. 둘 다 무료이고 광고가 없으며, 같은 성경 데이터와 같은 백업 파일을 씁니다.

안드로이드 앱

기능이 가장 많은 원래 앱 · Android 5.0 이상

  • 메모와 메모책: 필사·번역·설교 노트를 책처럼 따로 기록
  • 형광펜, 책갈피, 최근목록, 성경읽기통계
  • 음성 낭독(TTS)과 mp3 오디오 재생, 자동 스크롤
  • 홈 화면 오늘의 구절 위젯
  • 데이터 백업과 합쳐서 복구, 예전 데이터 폴더 가져오기
  • 전자책(e-ink) 기기 지원, 볼륨키로 넘기기
Google Play에서 받기 →

웹 앱 NEW

브라우저가 있는 모든 기기 · 설치하면 앱처럼

  • 아이폰·아이패드·맥·윈도우 PC·크롬북에서 바로 열고, 설치하면 인터넷 없이 읽기
  • 메모와 메모책: 저장하면 다음 절로 넘어가는 필사 입력
  • 형광펜(색·모양 고르기), 책갈피, 읽음 표시와 성경읽기통계
  • 절·장 전체 복사와 공유, 본문 오류 신고
  • 음성 낭독: 기기의 음성(TTS)으로 장을 읽고 다음 장으로 이어서, 속도 조절(브라우저가 지원할 때)
  • 안드로이드 앱과 같은 백업 파일로 백업하고 합쳐서 복구
  • 역본대조: 여러 역본을 화면 너비에 맞춰 여러 단으로
  • 검색: 검색어 두 개, 전체·구약·신약·주제별·책 범위
  • 가지고 있는 성경 파일(.lfa, .bdf)을 끌어다 넣기
  • 화면과 도움말 7개 언어, 글자·배경색, 밀어서 장 넘기기
웹 앱 열기 →

폰에서 쓰던 기록을 PC에서 이어서. 두 앱은 백업 파일이 같습니다. 안드로이드 앱의 백업을 웹 앱의 데이터 백업·복구에서 열면 메모·형광펜·책갈피·읽음 기록이 지금 기록과 합쳐집니다. 웹 앱의 백업은 안드로이드 앱 7.6.0부터 설정 > 데이터 복구로 열 수 있습니다.

두 앱은 같은 서버에서 같은 성경 파일을 받습니다. 안드로이드 앱에서 내보낸 성경 폴더(다운로드/LifoveBible/bible)를 웹 앱에 그대로 넣어 쓸 수도 있습니다.

무엇이 되나요?

웹 앱도 이제 메모·형광펜·백업과 음성 낭독까지 됩니다. mp3 재생·자동 스크롤과 위젯은 안드로이드 앱에만 있습니다.

웹 앱 설치하기

앱 스토어를 거치지 않고, 몇 번만 누르면 됩니다. 크기도 아주 작습니다.

  • 아이콘으로 열기주소창 없이 넓은 화면으로
  • 인터넷 없이받아 둔 역본은 비행기에서도
  • 저절로 업데이트새 버전이 나오면 알려 줍니다

사파리

  1. 사파리에서 lifovebible.github.io/web을 엽니다.
  2. 공유 버튼 □↑을 누릅니다. 아이폰은 화면 아래, 아이패드는 주소창 오른쪽에 있습니다.
  3. 목록을 올려 홈 화면에 추가를 누르고, 오른쪽 위 추가를 누릅니다.

iOS · iPadOS 16.4 이상

크롬 · 엣지 · 파이어폭스

  1. 주소창 오른쪽의 공유 버튼 □↑을 누릅니다. 엣지·파이어폭스는 메뉴 ⋯ 안에 있을 수 있습니다.
  2. 홈 화면에 추가 → 추가를 누릅니다.

크롬 (윈도우 · 맥 · 리눅스 · 크롬북)

  1. 웹 앱을 엽니다.
  2. 주소창 오른쪽 끝의 설치 아이콘(모니터에 화살표)을 누르고 설치를 누릅니다.

아이콘이 없으면 메뉴 ⋮ → 전송, 저장, 공유 → 페이지를 앱으로 설치

엣지 · 웨일

  1. 주소창 오른쪽의 앱 설치 아이콘을 누릅니다.
  2. 설치를 누릅니다.

엣지는 메뉴 ⋯ → 앱 → 이 사이트를 앱으로 설치로도 됩니다.

맥 사파리

  1. 사파리에서 웹 앱을 엽니다.
  2. 메뉴 막대 파일 → Dock에 추가를 누릅니다.

macOS 14(소노마) 이상. 파이어폭스는 설치 기능이 없으니 북마크해 두거나 크롬·엣지를 쓰세요.

웹 앱으로 설치

  1. 크롬에서 웹 앱을 열고 아래쪽 설치 안내를 누릅니다.
  2. 안 뜨면 메뉴 ⋮ → 앱 설치 또는 홈 화면에 추가.

삼성 인터넷은 주소창의 설치 아이콘 ↓ 또는 메뉴 ≡ → 현재 페이지 추가 → 홈 화면.

아이폰 사용자께. 아이폰에서는 브라우저와 홈 화면 앱이 저장 공간을 따로 씁니다. 설치한 뒤에는 홈 화면 아이콘으로 열고 역본을 다시 받으세요. 브라우저로만 쓰면 한동안 열지 않았을 때 받은 역본이 지워질 수 있으니 설치해서 쓰시기를 권합니다.
기록은 꼭 백업해 두세요. 웹 앱의 메모·형광펜·책갈피는 그 기기의 브라우저 안에만 저장됩니다. 브라우저 데이터를 지우거나 앱을 지우면 함께 사라지니, 메뉴 ☰ → 데이터 백업·복구에서 가끔 백업 파일을 받아 두세요. 오래 백업하지 않으면 웹 앱이 알려 드립니다.

새 소식과 다가오는 것들

사용자분들의 건의를 하나씩 살피며 계속 고쳐 가고 있습니다.

  1. 웹 앱11월 · 새로 들어감

    메모 · 형광펜 · 책갈피 · 백업, 그리고 7개 언어

    안드로이드 앱의 개인 기록을 웹 앱에도 넣었습니다. 메모책과 필사 입력, 나의형광펜목록·나의메모목록, 절·장 복사와 공유, 읽음 표시와 성경읽기통계, 안드로이드 앱과 백업 파일 주고받기. 형광펜 색·모양 고르기와 본문 오류 신고도 됩니다. 브라우저가 지원하면 기기의 음성으로 장을 읽어 주는 음성 낭독도 쓸 수 있습니다. 화면과 도움말은 한국어·영어·일본어·중국어(번체·간체)·스페인어·포르투갈어로 나옵니다.

  2. 7.6.0안드로이드 · 12월 초 예정

    메모책과 합쳐서 복구

    필사·번역·설교 노트용 메모책, 엔터로 저장하고 다음 절로 넘어가는 필사 모드, 백업을 지금 데이터와 합쳐 복구, 웹 앱 백업 열기, 절을 길게 눌러 본문 오류 신고.

  3. 그다음계획

    내 구글 드라이브로 동기화

    따로 서버를 두지 않고, 사용자 본인의 구글 드라이브로 여러 폰과 웹 앱의 메모·형광펜·읽음 기록을 맞추는 기능을 준비하고 있습니다.
